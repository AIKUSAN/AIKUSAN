**infrastructure & networks**<br>
I run Linux servers and the networks underneath them: MikroTik and pfSense on a telecom network serving 700+ concurrent subscribers, workstation and network rollouts for small offices, and the documentation that lets someone else take over. 10+ years hands-on, from the repair bench to the server rack.
